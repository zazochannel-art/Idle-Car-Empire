# Music

By default the pipeline **synthesises** its own background music (`scripts/vc/audio.py`, presets `drive`, `energy`, `satisfy`, `epic`) –
no third-party audio, so nothing to license.

To use your own **royalty-free / properly licensed** track instead, drop it here named after the preset
(e.g. `epic.mp3`, `drive.wav`). Files here always override the synthesised music. Keep the licence text next to the file.

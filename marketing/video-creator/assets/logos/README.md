# Logos

* The game logo is used from `../../assets/logo-cutout.webp` in the game repo (transparent cut-out of the real logo).
  Put a PNG at `assets/logos/logo-cutout.png` to override it.
* Optional: put the **official Google Play badge** (download it from Google's brand-guidelines page) at
  `assets/logos/google-play-badge.png`; the end card then uses it instead of the plain "PLAY FREE ON GOOGLE PLAY" button.
  It is not bundled because Google's badge has its own usage terms.
